# APP_STRUCTURE.md

## Overview
This document outlines the structure of the React Native app for the CleanOps Nexus Mobile project.

### File Structure
- `src/`
  - `components/` - Reusable UI components.
  - `screens/` - Screen components for each app view.
  - `navigation/` - Navigation configuration and routes.
  - `assets/` - Images, fonts, and static resources.
  - `styles/` - Global styles and theming.
  - `utils/` - Utility functions and helper classes.
  - `services/` - API clients and service handlers.
  - `state/` - State management (e.g., Redux, Zustand).
- `tests/`
  - Unit and integration test files.

### Details
- **Main Entry Point:** `App.tsx`
- **Framework Used:** React Native
- **Navigation Library:** React Navigation
- **State Management:** Redux (or as identified later)

This structure is a starting point and may evolve based on project needs.
